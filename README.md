# Artle

Jogo diário no estilo Wordle: adivinhe a carta de Magic: The Gathering só pela arte.

- Desafio diário **Geral** (qualquer carta) e desafios por cor: branco, azul, preto, vermelho, verde, multicolor e incolor.
- Três dificuldades: Fácil (arte inteira), Médio (zoom que abre a cada erro) e Difícil (zoom + desfoque, dicas mais lentas).
- 6 tentativas. Cada erro libera uma dica: custo de mana, tipo, coleção e raridade, texto e artista.
- Cronômetro, contagem de erros, estatísticas e resultado para compartilhar.
- Modo Treino com cartas aleatórias.

## Como rodar

É um arquivo só (`index.html`). Abra no navegador ou publique em qualquer hospedagem estática (este repositório usa GitHub Pages).

Os dados e as imagens das cartas vêm da [Scryfall API](https://scryfall.com/docs/api).
